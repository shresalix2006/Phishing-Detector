# 🦋 Phishing Detector

> A Victorian-themed tool that sniffs out phishing URLs, sketchy emails, and shady SMS messages — with style.

---

## 🔍 What is this?

Ever get a suspicious link and wonder *"is this gonna steal my identity?"* — well, now you don't have to guess! **Phishing Detector** uses smart heuristic scanning to tell you whether a URL, email, or SMS is safe, suspicious, or straight-up dangerous. All wrapped in a gorgeous Victorian fantasy aesthetic because why not look good while staying safe? 🖤✨

---

## ✨ Features

- 🔗 **URL Scanner** — detects phishing links, fake domains, brand impersonation, suspicious TLDs and more
- 📧 **Email Scanner** — spots urgency tactics, sensitive info requests, generic greetings and shady links
- 💬 **SMS Scanner** — catches smishing attacks, fake delivery notices, prize scams and shortened URLs
- ⚡ **Instant Heuristic Scan** — results in milliseconds
- 🧠 **Smart Pattern Detection** — deep analysis using custom scanning algorithms
- 🎨 **Victorian Fantasy UI** — dark parchment aesthetic with gold accents, ornate borders and candlelight glow
- 🦋 **Custom SVG Butterfly** — hand-crafted gold & black butterfly logo (no boring emojis here!)
- ⚠️ **Safety Confirmation Modal** — warns you before opening dangerous links
- 📊 **Risk Score & Confidence Meter** — so you know exactly how worried to be

## 🚀 How to Install & Run

**1. Clone the repository**
```bash
git clone https://github.com/shresalix2006/Phishing-Detector.git
cd Phishing-Detector/phishing-detector
```

**2. Install dependencies**
```bash
npm install
```

**3. Start the app**
```bash
npm start
```

**4. Open your browser at**
```
http://localhost:3000
```

That's it! No API keys or external services needed — everything runs locally in your browser.
